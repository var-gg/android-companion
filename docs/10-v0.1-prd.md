# v0.1 PRD

## Goal
Ship an installable public APK for a personal Android companion runtime that proves the thin-runtime / JSON-capability model.

## Success criteria
- Public GitHub repository exists
- Android project builds in CI
- Public APK URL exists
- Local manual testing path is documented
- Core actions return machine-readable JSON

## Required capabilities
1. Health ping / device info
2. Open URL
3. Launch app by package
4. List installed apps
5. Usage stats query when granted
6. Uninstall app request via Intent
7. Generic intent test surface
8. Self-update check + APK download/install handoff
9. Structured JSON success/error result model

## User persona
A technical owner/operator controlling their own Android device through a broader agent stack.

## Constraints
- Keep the Android app thin
- Avoid domain/business logic in the mobile client
- Do not hardcode server workflows
- Keep permission assumptions explicit
- Use GitHub Actions and public GitHub Releases for distribution

## Non-functional expectations
- Readable docs
- Clean repo structure
- Public-safe source tree
- No committed secrets
